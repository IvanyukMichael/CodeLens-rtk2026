# corpus_extra — дополнительный корпус для индексации

Снапшоты исходного кода двух открытых Python-библиотек, добавленные, чтобы база
индексации удовлетворяла требованию ТЗ **≥80 файлов** (gymhero = 47 файлов сам по
себе этого не даёт) и чтобы продемонстрировать масштабируемость ретрива на
посторонних «отвлекающих» чанках.

| Подпапка | Источник | Лицензия | Файлов .py |
|---|---|---|---|
| `click/` | [pallets/click](https://github.com/pallets/click) (пакет `src/click/`) | BSD-3-Clause | 17 |
| `rich/`  | [Textualize/rich](https://github.com/Textualize/rich) (пакет `rich/`) | MIT | 100 |

Лицензии оригиналов сохранены рядом: `click/LICENSE.txt`, `rich/LICENSE`.

**Почему именно эти библиотеки.** Они семантически далеки от домена gymhero
(CLI-фреймворк и рендеринг в терминале против auth / web-API / БД), поэтому их
чанки почти не конкурируют с эталонными ответами на официальные 15 вопросов —
официальная метрика Precision@5 проверена после переиндексации и не падает
(см. README §«База и метрика»). При этом они вместе дают +117 файлов и +1608
чанков «отвлекающего» кода — честная нагрузка на ретрив.

**Важно:** официальная метрика чемпионата считается только по корпусу `gymhero`.
Этот корпус — для требования по размеру базы, демонстрации масштаба и поиска по
постороннему коду в UI; chunk_id здесь имеют собственные префиксы (`click/…`,
`rich/…`) и не пересекаются с `gymhero/…`.
